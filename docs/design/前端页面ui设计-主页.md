# 首页与全站导航设计指示

## 1. 首页定位与内容结构

首页将从目前的“抽象轨道状态面板”转为“真实内容开场”，并采用具有电影感的冷色数字艺术视觉语言。

首屏左侧是清晰身份表达：姓名、一句话定位、简短介绍和一个主行动按钮。标题与正文应具有明确的阅读层级，避免被背景或装饰效果干扰。

首屏右侧使用真实精选照片、作品拼贴或与个人创作相关的视觉内容，并放置一个小型“蔚蓝地球陪伴组件”；不使用占据大面积的纯装饰性轨道状态面板。地球组件只作为具有生命感和互动感的视觉锚点，不能抢夺作品、照片和文字的主体地位。

首屏不再强制占满整屏；首屏底部应露出下一段内容，让用户自然知道可以继续浏览。

首页下面依次呈现「最新文章 / 精选作品 / 近期影像」三类真实内容，而不是仅提供三个空洞的入口卡片。每个内容区域应展示真实文章摘要、项目封面、照片缩略图、标签、日期或状态信息，使访客能够直接感知站点内容。

页尾以简洁个人介绍、联系入口和版权信息收束。

## 2. 全站导航采用“两层信息架构”

| 主导航 | 放置内容 |
| --- | --- |
| 首页 | 个人入口与最近内容 |
| 文章 | 文章列表、文章详情、归档 |
| 作品 | 项目、实验、案例 |
| 影像 | 相册、照片详情 |
| 关于 | 个人介绍、能力与联系 |
| 工具入口 | Skills、AI、登录、后台，仅在登录状态、右侧工具区或移动端折叠菜单中出现 |

这样，访客首先看到的是“内容”，而不是系统能力。归档不再单独占用主导航；Skills、AI、登录、后台收入右侧工具区或移动端菜单底部，避免公开导航显得拥挤、技术味过重。

桌面端导航应固定在页面顶部，采用低对比度深色毛玻璃层：左侧为简洁的个人标识与站点名称，中部为主导航，右侧为声音开关、状态提示、登录或账户入口。当前页面使用细下划线、微弱光线或浅色底作为状态提示，不使用厚重的胶囊按钮。

## 3. 视觉规范

整体视觉采用“深空电影感数字艺术 × 个人内容档案”的基调。页面不是普通深色背景加卡片，而是以一幅全屏、具有真实尺度感的电影画面作为首屏环境：界面层轻覆于场景之上，内容、人物、天体、雾气和光线共同构成完整画面。

### 3.1 首屏场景与空间构图

首屏背景使用全宽沉浸式场景图，而不是纯色、渐变或抽象纹理。画面应由以下层次构成：

- 上方与中部：一颗巨大的灰蓝色天体弧面从画面上沿与左侧延伸至中部，占据主要空间；它应有真实表面质感、低对比度阴影和柔和边缘光，形成强烈的尺度感，但不压住左侧标题与右侧地球组件。
- 下方：空旷、微湿润或带细微纹理的深色平原延展至地平线，作为页面底部内容卡片的视觉基底。
- 画面中下部：一个极小的孤独人物背向观者，站在平原上望向远方微亮的地平线。人物只承担叙事与尺度参照，不应成为可识别的人像主体。
- 地平线：保留一条极细、低亮度的冷白或暖琥珀色光带，作为画面纵深与希望感来源。
- 空气与细节：使用薄雾、稀疏星点、微小蓝色像素粒子、远处云层和柔和体积光；所有环境细节必须克制，不得形成喧闹的科幻特效背景。

整体色彩以深蓝灰、黑蓝、雾灰和冷白为主，少量冰青光点用于数字感提示，极少量暖金或琥珀色仅用于地平线、微小提示灯或生命感细节。画面应安静、孤独、沉思、辽阔，具有电影镜头般的景深、雾化和尺度对比。

### 3.2 界面层与毛玻璃材质

导航、正文、按钮和内容卡片不是独立的平面模块，而是覆盖在电影场景上的半透明界面层。整体采用深色毛玻璃质感：

- 毛玻璃底色使用深海军蓝或蓝黑色，透明度适中，使背景可隐约透出，但不影响文字阅读。
- 背景模糊应轻微且真实，避免高模糊导致所有区域像塑料面板。
- 边框采用极细的低亮度蓝灰或白色半透明线，圆角柔和但不过度圆润。
- 阴影以向下扩散的深蓝黑阴影为主，辅以极弱的冷色边缘辉光，避免厚重悬浮感。
- 同一页面中的导航、按钮、状态标签和三张内容卡片必须使用统一的透明度、边框、阴影与圆角系统。

### 3.3 顶部导航视觉

顶部导航采用参考图中的横向悬浮式毛玻璃导航栏：

- 导航栏位于页面顶部并保留外边距，不与浏览器边缘贴合。
- 它是一个横向、宽幅、低高度的深色半透明圆角容器，覆盖在背景天体与天空区域上。
- 左侧放置简洁的个人标识、`FY` 字母标记和站点名称 `ARCHIVE`。
- 中部放置“首页 / 文章 / 作品 / 影像 / 关于”五项主导航，间距均衡，保持安静、清晰、居中。
- 当前页面使用细短的冰青色下划线或底部微光标记；不得使用夸张高亮、厚重胶囊或复杂边框。
- 右侧依次为声音开关、小型在线状态点、登录或账户入口。登录按钮采用低对比度描边毛玻璃样式，不使用高饱和填充色。
- 导航滚动后保持固定，并适度增强背景模糊与不透明度，保证文字在明亮天体弧面前仍可读。

### 3.4 首屏文字与行动按钮

首屏文字位于画面左侧中部，与右侧地球组件和中央下方人物形成稳定三角构图：

- 眉题使用小字号冰青色等宽字体，例如“DEVELOPER & DIGITAL ARTIST”或实际个人定位。
- 主标题采用大字号、高可读性浅灰白字体，允许两行或三行分段，字距略紧，形成参考图中简洁而有力量的叙事中心。
- 主标题末尾可使用一个冰青色句点、短线或极小光点作为视觉收束，但不能加入大面积渐变文字。
- 正文为两行以内的蓝灰色简介，宽度受控，避免横向过长。
- 主行动按钮使用冰青色低饱和填充与柔和阴影；次级按钮采用深色毛玻璃描边。每个页面最多一个高亮主按钮。
- 标题、正文和按钮必须始终位于背景中对比稳定的暗部，不得压在巨型天体的最亮区域上。

### 3.5 蔚蓝地球陪伴组件

首屏右侧设置一个独立的小型“蔚蓝地球陪伴组件”，其位置、尺寸和信息层级参考图中右侧小型天体组件，但主体由月球改为蔚蓝地球。

- 地球位于首屏右侧中部，尺寸约为 160–200px；它明显小于背景中的巨大天体，不得成为首屏主视觉。
- 地球拥有深蓝海洋、低饱和青绿色陆地、轻薄云层、暗侧阴影和冰青色大气边缘辉光，整体风格介于精致数字插画与低饱和写实之间。
- 背景中的巨大天体负责空间尺度与氛围；右侧小型蔚蓝地球负责个人互动与陪伴感。两者共享冷蓝灰光照体系，但必须在尺寸、饱和度和清晰度上明确区分。
- 地球周围只允许保留少量稀疏蓝色像素粒子、短弧形路径提示和细微边缘辉光；不使用大型水平椭圆轨道，不使用复杂行星环，不制造多余装饰。
- 地球下方可放置简洁等宽标签，例如 `ORBITAL COMPANION`，并配一个小型暂停/播放控制；标签与控件应弱化，不能抢占标题或内容卡片的注意力。

小猫采用圆润、紧凑、黑色、低细节、侧身奔跑的原创卡通形象。它在地球上运行时应非常小，沿地球外圆周的弧线跑动，如同贴着圆形边界绕地球跑；不得使用水平直线、赤道横向轨道或悬浮姿态。初始跑动状态只显示侧身轮廓、耳朵、尾巴与奔跑动作，不强调正面眼睛和面部细节。

### 3.6 底部三栏内容卡片

首屏底部紧接着展示「最新文章 / 精选作品 / 近期影像」三类真实内容，卡片布局采用参考图中的横向三栏结构：

- 三张卡片位于页面下方，覆盖在平原背景上，与首屏文字和地球组件处于同一视觉画面中。
- 卡片高度相近、宽度平衡、间距统一，使用深色半透明毛玻璃材质。
- 每张卡片顶部显示冰青色小标题、对应图标和“更多”入口；更多入口采用细小箭头与低对比度文字。
- 最新文章卡片展示一张文章封面、标题、两行摘要、日期与少量标签。
- 精选作品卡片展示项目缩略图、项目名称、简介、技术标签或状态信息。
- 近期影像卡片展示两至三张照片缩略图，并提供进入影像日志或相册的入口。
- 卡片内的图片应是实际文章、项目和影像内容的缩略图，保持真实创作档案的属性；不可只使用无意义的抽象科技贴图。
- 卡片悬停时只出现轻微上浮、边框亮度提升或背景透光变化，不产生夸张缩放、闪烁或遮挡背景的动画。

### 3.7 文字、图片与动效

主文字使用偏冷的浅灰白，辅助文字使用低亮度蓝灰色。避免纯白与纯黑造成过强对比，也避免透明度过低导致在背景图上难以阅读。

照片、项目封面和影像内容仍是最重要的视觉元素。毛玻璃卡片、环境光、背景天体和蔚蓝地球组件只服务于内容，不与内容抢注意力。

保留系统中文字体优先策略；标题更大、更紧凑，正文控制在舒适行宽。英文标签、状态、时间或技术信息可使用简洁等宽字体。

动效仅用于导航展开、页面切换、卡片悬停、信息层级变化、蔚蓝地球组件和小猫的明确互动状态。不得做无信息价值的大面积自动旋转、无规律漂浮、高频闪烁或持续强光呼吸效果。所有动态效果必须遵循“减少动态效果”系统偏好。

## 4. 全站交互基线

顶部导航固定，但滚动后应适度缩紧并增强毛玻璃背景与边界，保证在复杂背景上仍可读且不遮挡内容。

当前页面只使用细下划线、浅色底或微弱辉光，不使用过重的胶囊按钮。

主按钮每个页面最多一个；次级操作使用文本、描边按钮或低对比度玻璃按钮。

手机端导航改为全屏或半屏抽屉，链接高度至少 44px，并把账户、Skills、AI、登录和后台等工具操作与公开导航清晰分隔。

每个列表页都统一提供加载、空数据、失败和筛选结果反馈。加载状态应保持页面骨架与内容层级，空状态应告知用户下一步可做什么，失败状态应提供重试或返回路径。

## 5. 首页“蔚蓝地球微世界”组件

首页视觉主角之一是一个小型“个人轨道微世界”组件，但它不是首屏的大型主视觉，也不应遮挡内容。

组件主体由一颗蔚蓝地球构成。地球应具有蓝绿色海洋、浅云层、深蓝夜侧、细微陆地纹理和淡青色大气边缘辉光；整体风格为精致、轻量、可交互的数字插画，而不是巨大的写实天体。

地球建议位于首屏右侧真实作品拼贴或背景视觉附近，桌面端直径约为 160–200px，移动端约为 120–140px。它应与页面背景中的巨大天体、冷蓝色雾气、地平线光线和毛玻璃组件保持统一的光照、色彩与材质语言，但仍明确作为独立小组件存在。

地球上是一只原创的黑色小猫角色。小猫采用用户提供参考图所体现的“圆润、紧凑、黑色、低细节、侧身奔跑”的卡通动作与轮廓感觉；不得直接复制任何现有角色的具体造型、五官、服饰、纹样或身份设定。

初始状态下，小猫沿蔚蓝地球的外圆周轨迹侧身奔跑，路径应贴合地球圆形边缘，如同沿圆形边界绕地球跑动；不能使用水平椭圆轨道，也不能让小猫悬浮在地球赤道的直线轨道上。

小猫在地球上奔跑时应进一步缩小，建议约为地球直径的 12%–15%。此状态只展示侧身轮廓、耳朵、尾巴、四肢与奔跑节奏，不强调正面眼睛或面部表情。地球外缘可配合极少量弧形路径提示、淡青色辉光和稀疏粒子，但不能形成复杂或喧闹的轨道装饰。

鼠标靠近地球时，小猫可减速、观察、轻微摆尾或停在地球边缘；点击地球可触发短暂互动，例如追逐一颗光点、跳跃、绕行加速后回到正常跑动。

## 6. 小猫活动状态

页面停留一段时间后，小猫可以离开地球，在首页各内容模块间活动：趴在作品卡片上休息、追逐发光粒子、从影像模块边缘探头、在文章标题旁打盹。

小猫离开地球后，才允许出现更丰富的正面、侧脸、眼睛、睡眠、好奇、嬉闹和跳跃等状态。即使在这些状态下，小猫也始终不遮挡按钮、正文、照片主体和键盘焦点；它本质上是环境角色，而不是干扰操作的弹窗。

状态可以按轻量状态机实现：

| 场景 | 小猫行为 |
| --- | --- |
| 首次进入 | 沿蔚蓝地球外圆周侧身跑动，建立首页记忆点 |
| 鼠标靠近地球 | 减速、观察、轻微摆尾或停在地球边缘 |
| 点击地球或互动元素 | 追光点、跳跃、短暂加速绕行后回到地球 |
| 停留一段时间 | 离开地球，随机访问文章、作品或影像模块 |
| 用户滚动 | 躲到屏幕边缘、回到地球，或跟随至下一个可见内容区 |
| 长时间无操作 | 在某个卡片角落休息、蜷缩、打盹或轻微摆尾 |
| 减少动态效果 | 停在蔚蓝地球边缘，仅保留静态插画与必要状态提示 |

## 7. 音效

音效应作为“可选环境层”，而不是自动播放。浏览器通常会拦截未经点击触发的声音，且自动播放会影响阅读体验。

导航右侧可放一个简洁的声音开关：

- 默认静音，用户主动开启后才播放。
- 声音以极轻的环境氛围为主：低频空间环境声、细微电子脉冲、远处风声，以及小猫奔跑、跳跃或追逐光点的短反馈。
- 不循环播放明显旋律，不在每次交互都发出声音。
- 记住用户选择；开启“减少动态效果”时默认关闭环境音效。
- 声音开关必须提供清晰的开启、关闭与当前状态反馈。

## 8. 技术实现原则

蔚蓝地球、小猫、圆周跑动路径和少量粒子优先使用原创 SVG + CSS/Canvas 动画，而不是大体积视频。Vue 负责状态机、交互调度、页面可见性判断、减少动态效果偏好和用户声音偏好的持久化。

地球组件、卡片区域和导航应采用分层结构：背景图层、内容图层、毛玻璃界面层、地球组件层和小猫活动层彼此独立。小猫活动层默认不拦截内容点击与键盘操作，只有地球组件本身的明确交互区域可被操作。

这样可以保证首屏轻量、清晰、可访问，并适配不同屏幕。移动端应降级为静态蔚蓝地球与侧身小猫，点击地球才播放短动画；小猫离开地球的复杂跨模块活动可关闭或显著减少，以避免耗电、滚动卡顿和遮挡内容。

## 9. 组件化与后续重构

实现上先扩展现有全局变量为完整设计令牌，至少包含背景层级、深色毛玻璃透明度、边框、阴影、文字层级、冰青强调色、暖色点缀、间距、圆角、断点、动效时长和减少动态效果策略。

建立统一的导航、按钮、内容区标题、玻璃卡片、标签、空状态、加载状态、声音开关和地球陪伴组件。

然后重构首页和公开站布局；后台保留现有深色控制台方向，与公开站形成“电影感作品档案 / 高效率管理空间”两种明确场景。
