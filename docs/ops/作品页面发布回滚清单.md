# 作品页面发布与回滚清单

## 发布顺序

1. 备份生产 SQLite，并记录备份文件校验值。
2. 执行 `pnpm exec prisma migrate deploy`，确认 `prisma migrate status` 为 up to date。
3. 发布后台草稿、媒体、区块、资源和提示词管理能力，验证未登录请求返回 401。
4. 发布公开 API，验证公开 DTO 只包含已发布且已审核内容。
5. 发布 `/portfolio` 与详情 UI，验证空态、404、媒体失败回退和移动端布局。

## 回滚

- UI/API 回滚只切换部署版本或 feature flag，不删除新表和新数据。
- 若公开接口异常，恢复旧读取路径；保留新结构化数据供后台继续修复。
- 若迁移失败，停止发布并恢复 SQLite 备份；不得执行删除迁移或手工删除审核历史。
- 回滚后重新执行权限、公开 DTO、媒体白名单和缓存失效检查。

## 禁止项

- 不在公开响应中输出 `storageKey`、本地路径、审核意见、草稿区块或提示词正文。
- 不把管理员预览链接、调试信息或任意嵌入域名暴露到公网。

## Release evidence (2026-08-01)

- Local production-like SQLite snapshot created at `nuxt-app/.data/backups/ecs-prod-pre-portfolio-release-20260801.db` (466,944 bytes; SHA-256 `FB1D16CEA0A755DA2088CA5EE9A2C9D0567E64F2A957E392E2F2D455D923FC43`).
- `pnpm exec prisma migrate deploy` reports no pending migrations; `pnpm exec prisma migrate status` reports the database is up to date (18 migrations).
- Legacy scalar fields are migrated once into normalized records and removed from the Portfolio schema; runtime code has no legacy-field reads or fallback paths.
- Portfolio uploads are constrained to approved MIME types and 50 MB; media processing metadata and derivative readiness are required by the publish gate.
- Portfolio endpoints use uncached server reads in this release; deployment restart is the cache invalidation action, with no CDN purge assumed.
- Runtime smoke checks: public pages/API return 200; unauthenticated admin portfolio and upload endpoints return 401.
