  权限和分组设计

  已统一为：

  - admin：管理员，可进入后台、审核照片、管理用户、管理相册、管理文章和执行受保护操作。
  - user：普通用户，只能上传照片、查看自己上传的照片、编辑自己照片的标题/描述，不能管理相册、用户、文章或 Skill。
  - 删除了“访客”和“朋友”作为角色的设计。旧数据中的 friend/viewer 会按普通用户处理。

  分组现在是独立于角色的可见性标签：

  - 一个用户可以属于多个自定义分组。
  - 管理员可以在用户管理中输入任意分组名称，回车添加或删除。
  - 照片和相册可以设置为：
      - 公开
      - 私有
      - 指定分组

  - 指定分组资源只对属于任一指定分组的用户可见。

  照片归属和权限

  普通用户上传的照片：

  - 上传者始终可以在“照片管理”中看到自己的照片，即使管理员后来修改了可见性。
  - 普通用户不能修改审核状态、公开状态或分组权限。
  - 管理员可以审核、拒绝、修改可见性和分组。
  - 管理员将照片改为其他分组后，原上传者仍能管理自己的照片元数据，但不再自动拥有该照片的展示权限。

  私有照片的含义：

  - 普通用户：只有上传者本人可见。
  - 管理员：可查看和审核。
  - Ubuntu：只负责保存原图，不代表 Ubuntu 上的所有登录用户都能通过网站访问。
  - 未授权用户：无法通过网站 API 访问。

  上传流程

  已选择并实现：

  - 前台只负责上传、填写标题、选择可见范围、选择可选相册。
  - 普通用户上传后默认进入 pending 审核。
  - 管理员上传后默认直接 approved + published。
  - 上传时可以选择多个当前可访问的相册。
  - 指定分组可见时，只能选择当前用户所属分组。
  - 不选择相册时，照片可以独立存在。

  上传入口现在是 /albums 上的“上传照片”按钮，点击后打开弹窗，不再占用整块页面空间。
